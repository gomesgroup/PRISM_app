# Menu Page

Main menu page for the Amides WebApp with an animated Game of Life background.

## Features

- Animated Game of Life background using cellular automaton
- Responsive design for all screen sizes
- Smooth, symmetrical patterns using "highlife" rules
- Performance optimized with intersection observer

## Running the Server

```bash
cd menu
python app.py
```

The server will start on `http://0.0.0.0:5000`

## Port Configuration

- Menu: Port 5000
- Reactor: Port 5001  
- Heatmap: Port 8000
